ENIE LIVE RIDER MAP ACCURACY UPDATE

This is an incremental patch for the project after installing ENIE-live-rider-map-update.zip.
Extract this ZIP into the project root and allow the listed files to be replaced.

What it changes:
- Replaces the broad OpenStreetMap iframe with a zoomable Leaflet map (default zoom 18).
- Moves the rider marker as fresh coordinates arrive (admin refresh every 5 seconds).
- Sends and stores the phone browser's reported GPS accuracy in metres.
- Draws an accuracy circle and displays the reported accuracy beside the map.
- Requests fresh, high-accuracy browser readings (maximumAge 0, timeout 60 seconds).
- Adds an idempotent database column migration in database/database.go; it runs when the app starts.
- Allows the Leaflet assets from unpkg.com in the Content Security Policy.

Important accuracy note:
The circle represents the accuracy estimate reported by the phone/browser. The site cannot make GPS more precise than the phone's actual signal. Indoors, near tall buildings, or with weak GPS reception, the circle may be large. Ask the rider to test outdoors with phone Location and Precise Location enabled.

After copying:
1. Run: gofmt -w database/database.go handlers/rider_portal.go handlers/admin.go handlers/admin_rider_assignment.go handlers/admin_riders.go
2. Run: go test ./...
3. Commit and push to GitHub so Render deploys.
4. Restart the rider's sharing session by opening the rider link and tapping Start sharing again.

No existing orders, dishes, or customer records are deleted. The new accuracy column is added with ALTER TABLE ... ADD COLUMN IF NOT EXISTS.
