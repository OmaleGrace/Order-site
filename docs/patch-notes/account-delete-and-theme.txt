Account deletion + appearance (light / dark / follow device)

1. Delete account  (Account > Edit profile > Delete account)
   - Needs the password (password accounts) and the word DELETE typed in.
   - Erases: name, email, phone, address, photo, sessions, cart, favourites, notifications,
     push devices, support tickets. The email can be used to sign up again.
   - Keeps (anonymised as "Deleted user"): past orders, so shops keep their sales and refund records.
   - Blocked while: the person owns a shop, is an admin, has an order being prepared, or has wallet money.
   - Run migration 0006 (applied automatically on start).

2. Appearance  (Account page > Appearance)
   - Light, Dark, or Device (follows phone/computer setting). Saved on the account and remembered per device.
   - static/css/dark.css is GENERATED: after changing any stylesheet run  python3 tools/gen_dark.py
     Hand fixes go in static/css/dark-fixes.css.
