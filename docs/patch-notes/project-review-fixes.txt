Project review fixes
--------------------
1. handlers/payment.go: a failed ClearCart after a committed payment is now only logged (callback and webhook),
   so paid customers no longer see an error and the confirmation email / shop alert are not skipped.
2. safe/safe.go (new): Recover() for background jobs. Used in email.Send, notifyVendorNewOrder, every
   "go func" job, and the scheduled-orders loop in main.go, so one panic cannot end the whole program.
3. main.go: if ListenAndServe fails (e.g. port taken) the program now exits instead of idling.
4. brand.SiteURL() accepts APP_BASE_URL, PUBLIC_BASE_URL or SITE_URL; used by password reset and rider links.
   Password reset sends nothing (and logs why) when no site address is configured.
5. handlers/checkout.go: vendorRows.Err() is checked before the one-shop-per-order rule.
6. .env.example added (every setting the code reads, with defaults).
Not changed: ~37 display loops without rows.Err(); loyalty-redemption failure after a successful payment.
